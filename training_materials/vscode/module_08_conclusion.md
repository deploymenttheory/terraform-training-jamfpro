# 🎓 Module 08 - Continue Your VS Code Learning Journey

*Duration: 10 minutes | Labs: 0 | Difficulty: 🟢 Beginner*

---

## 🏁 What You've Built

Across this course you turned VS Code from "the thing you type into" into a configured, personal toolchain:

- ✅ A navigable mental map of the UI, driven from the keyboard via the Command Palette
- ✅ An extension set for Terraform work: HashiCorp Terraform, GitLens, indent-rainbow, Better Comments
- ✅ Multi-file editing skills: splits, navigation, IntelliSense, refactoring, and your own snippets
- ✅ A Git workflow - stage, diff, commit, sync, branch, resolve conflicts - entirely inside the editor
- ✅ A tuned terminal with a purpose-built `TF_LOG` debug profile
- ✅ One-keystroke `terraform fmt`/`validate`/`plan` via tasks, and a debugging toolkit for scripts *and* Terraform

Notice the theme: settings, extensions, snippets, tasks, and launch configurations all live in files, many of them in `.vscode/` inside the repo. Your editor setup is itself configuration as code.

## 🧭 Keep Going

**Bookmark these three:**

- 📖 [The documentation home](https://code.visualstudio.com/docs) - when you wonder "can VS Code do X?", the answer is here
- ⌨️ [Keyboard shortcuts](https://code.visualstudio.com/docs/configure/keybindings) - including the printable reference sheet (Command Palette → **Help: Keyboard Shortcuts Reference**). Learn a couple a week; rebind what doesn't fit your hands
- 💡 [Tips and tricks](https://code.visualstudio.com/docs/editing/tips-and-tricks) - the official grab-bag; skim it every few months and you'll always leave with something new

**Worth exploring next, as the need arises:**

- 🔄 [Settings Sync](https://code.visualstudio.com/docs/configure/settings-sync) - roam your whole setup (settings, extensions, keybindings, snippets) across machines
- 👥 [Profiles](https://code.visualstudio.com/docs/configure/profiles) - separate extension/setting sets per context (e.g. a lean "Terraform" profile vs a "docs writing" profile)
- 🖥️ [The editing tutorial](https://code.visualstudio.com/docs/editing/getting-started) - a fast structured recap of the fundamentals, useful for onboarding teammates
- 🌐 [Remote development](https://code.visualstudio.com/docs/remote/remote-overview) - edit on servers, containers, or WSL with the full editor experience
